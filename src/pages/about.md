## 你好，这里是坤

这是一个用来记录技术与热爱的地方。

代码里有值得反复思考的问题，动漫里有想一直记住的瞬间。我想把它们放进同一个小站，慢慢积累自己的笔记和答案。

### 这里会写什么

- **技术笔记**：Java、AI、算法与计算机基础。
- **工具与部署**：开发环境、Git、服务器，以及那些让工作顺手一点的小工具。
- **站点手记**：项目记录、博客更新与偶尔的随想。

### 我喜欢的世界

火影忍者、海贼王、奥特曼与死神。首页的「换个世界」可以切换壁纸，选择会保存在当前浏览器中。

### 关于这个博客

这个小站基于 [Koharu](https://github.com/cosZone/astro-koharu) 定制，设计灵感来自 [余弦の博客](https://blog.cosine.ren/)。感谢开源作者提供的主题与文档。

文章使用 Markdown 编写，通过 Git 管理。可以通过 [RSS](/rss.xml) 订阅更新，也可以 [下载本站源码](/blog-source.tar.gz)，在自己的 Git 仓库里继续维护。

当前几篇文章是开站说明与排版示例，后续可以替换成真正的技术笔记。
